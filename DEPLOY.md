# Запуск приложения на VPS/VDS — пошаговая инструкция для новичка

В этом документе — весь путь от пустого сервера до работающего сайта с уведомлениями
на телефоне. Идите по шагам по порядку, ничего не пропускайте.

---

## Шаг 0. Что вам понадобится

1. **VPS/VDS-сервер** с Ubuntu 22.04 или 24.04.
   Такие серверы продают, например: Timeweb Cloud, Beget, Reg.ru, Selectel, FirstVDS.
   Достаточно самого дешёвого тарифа (1 ядро, 1–2 ГБ RAM).
2. **Домен** (ваше имя сайта, например `reminders.example.ru`). Домен нужен для
   бесплатного HTTPS-сертификата — а HTTPS обязателен для уведомлений на телефоне.
   Без домена приложение тоже заработает по IP, но **push-уведомления на телефоне не будут работать**.

> Если домена нет — купите его у регистратора (например reg.ru, beget.ru, timeweb.com)
> и в панели управления добавьте к нему записи типа «A» со значением IP-адреса вашего сервера.
> Обычно записи «A» добавляются для `@` и для `www`. Изменения DNS действуют от 10 минут до нескольких часов.

## Шаг 1. Подключитесь к серверу

В Windows откройте **PowerShell** (или используйте PuTTY) и введите:

```
ssh root@ВАШ_IP_СЕРВЕРА
```

Например: `ssh root@95.213.10.10`

Введите пароль (при вводе пароль не отображается — это нормально).
Если хостинг дал доступ через ключ — просто подключитесь.

## Шаг 5. Настройте конфигурацию (самое важное!)

В файле `config.py` есть две настройки, которые нужно поменять. Сначала объясню, что это.

### Что такое REMINDER_SECRET

Это **секретный ключ** приложения — просто длинный случайный набор букв и цифр.
Он используется для подписи данных (сессий). Главное правило: он должен быть
**случайным и только у вас** — не оставляйте значение по умолчанию `change-me-on-server`.

Сгенерировать такой ключ можно командой прямо на сервере:

```
python3 -c "import secrets; print(secrets.token_hex(32))"
```

Она выведет что-то вроде `f9a21c...` (64 символа). Скопируйте вывод.

### Что такое REMINDER_BASE_URL

Это **публичный адрес**, по которому приложение будет доступно в интернете.
Он нужен для работы push-уведомлений (в нём указывается email для сервиса уведомлений).
Запишите туда адрес вашего сайта **с `https://`**, например:

```
https://reminders.example.ru
```

Если вы пока тестируете без домена, укажите IP:
```
http://95.213.10.10
```
(но уведомления на телефоне без HTTPS не заработают — домен всё равно понадобится).

### Как внести настройки — есть два способа

#### Способ А. Простой — отредактировать файл config.py

Откройте файл в редакторе:

```
nano /opt/Reminder/config.py
```

Найдите эти две строки:

```
SECRET_KEY = os.environ.get('REMINDER_SECRET', 'change-me-on-server')
BASE_URL = os.environ.get('REMINDER_BASE_URL', 'http://127.0.0.1:5000')
```

Замените их на:

```
SECRET_KEY = 'ВАШ_СГЕНЕРИРОВАННЫЙ_КЛЮЧ_ВСТАВЬТЕ_СЮДА'
BASE_URL = 'https://ваш-домен.ru'
```

> ВАЖНО: в Python строки пишутся в кавычках — одинарных или двойных.
> Ничего другого в этих строках не меняйте, не удаляйте запятые и скобки.

Сохранить файл в `nano`: нажмите `Ctrl+O`, затем `Enter`, затем `Ctrl+X` (выйти).

#### Способ Б. Правильный — переменные окружения (для тех, кто не боится)

Тогда сам `config.py` трогать не нужно: значения передаёт systemd (см. Шаг 8).
Он подхватывается автоматически, потому что в файле написано `os.environ.get(...)` —
это значит «возьми значение из переменной окружения, если она есть».

## Шаг 8. Настройте автозапуск через systemd

systemd — это менеджер служб Linux. Он будет сам запускать приложение при
перезагрузке сервера и перезапускать его, если оно упадёт.

Создайте файл службы:

```
sudo nano /etc/systemd/system/reminder.service
```

Вставьте туда такой текст (замените `ubuntu` на вашего пользователя — узнайте его командой `whoami`;
замените ключ и адрес на свои):

```ini
[Unit]
Description=Reminder app
After=network.target

[Service]
WorkingDirectory=/opt/Reminder
ExecStart=/opt/Reminder/.venv/bin/gunicorn -w 1 -k gthread --threads 8 --timeout 120 -b 127.0.0.1:5000 run:app
Restart=always
User=ubuntu
Environment=REMINDER_SECRET=ВАШ_СГЕНЕРИРОВАННЫЙ_КЛЮЧ
Environment=REMINDER_BASE_URL=https://ваш-домен.ru

[Install]
WantedBy=multi-user.target
```

> **Важно:** строка `-w 1` означает «один процесс». Планировщик напоминаний живёт
> внутри приложения, поэтому рабочих процессов должно быть ровно **один**, иначе
> напоминания начнут дублироваться.

Сохраните (`Ctrl+O`, `Enter`, `Ctrl+X`) и выполните:

```
sudo systemctl daemon-reload
sudo systemctl enable reminder
sudo systemctl start reminder
sudo systemctl status reminder
```

В выводе `status` должно быть слово `active (running)`.
Если что-то не так, смотрите логи:

```
sudo journalctl -u reminder -n 50
```

## Шаг 9. Настройте Nginx (веб-сервер)

Создайте конфиг:

```
sudo nano /etc/nginx/sites-available/reminder
```

Вставьте (замените `ваш-домен.ru` на свой):

```
server {
    listen 80;
    server_name ваш-домен.ru;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_buffering off;
    }
}
```

Включите конфиг и проверьте:

```
sudo ln -s /etc/nginx/sites-available/reminder /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx
```

`nginx -t` должен написать `syntax is ok` и `test is successful`.

## Шаг 10. Выдайте бесплатный HTTPS-сертификат (обязательно!)

Уведомления на телефоне работают только по HTTPS. Получить бесплатный сертификат
Let's Encrypt очень просто:

```
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d ваш-домен.ru
```

Отвечайте на вопросы: укажите email, согласитесь с условиями (Y),
на вопрос про перенаправление HTTP→HTTPS выберите **2** (Redirect).
Certbot сам настроит всё и сделает автоматическое продление сертификата.

---

## Шаг 11. Настройте фаервол

```
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw enable
```

На вопрос «Proceed?» ответьте `y`. Это откроет только SSH и порты 80/443.

## Шаг 13. Тест на телефоне

1. На телефоне откройте **https://ваш-домен.ru** (в Chrome на Android, в Safari на iPhone).
2. Перейдите в **Настройки** → нажмите **«Включить уведомления»** →
   в появившемся запросе браузера разрешите уведомления (**Разрешить / Allow**).
3. Нажмите **«Проверочное уведомление»** — должно прийти уведомление с текстом
   «Уведомления работают!».
4. Нажмите **«Добавить на главный экран»** (в Chrome: меню ⋮ → «Добавить на главный экран»;
   на iPhone: «Поделиться» → «На экран „Домой"»). Приложение станет как обычная иконка на рабочем столе.
5. Добавьте лекарство с временем на пару минут вперёд и убедитесь, что уведомление
   приходит поверх всех окон со звуком.

## Частые вопросы и проблемы

**Сайт не открывается.**
Проверьте по порядку:
```
sudo systemctl status reminder
sudo nginx -t
curl -I http://127.0.0.1:5000
```
`curl` должен вернуть `HTTP/1.1 200`. Если нет — смотрите логи: `sudo journalctl -u reminder -n 50`.

**Уведомления не приходят на телефон.**
- Проверьте, что открываете сайт по `https://`, а не `http://` (уведомления работают только по HTTPS).
- Проверьте, что разрешили уведомления в браузере телефона.
- Проверьте, что в настройках приложения написано «Уведомления включены».
- Если страница открывается через http — добавьте сертификат (Шаг 10) и откройте https.

**Напоминания дублируются.**
Убедитесь, что в systemd стоит `-w 1` (один процесс). Скажите мне, если после перезапуска не помогло.

**Как обновить приложение до новой версии?**
```
cd /opt/Reminder
git pull
.venv/bin/pip install -r requirements.txt
sudo systemctl restart reminder
```

**Как посмотреть логи приложения?**
```
sudo journalctl -u reminder -f
```
(`-f` — следить в реальном времени, выход — `Ctrl+C`)
